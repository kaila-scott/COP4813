Spirograph Canvas Drawing

This page uses the HTML5 canvas and JavaScript to draw a Spirograph pattern. The program uses the required Spirograph equations:

x = (R + r) × cos(t) - (r + O) × cos(((R + r) / r) × t)

y = (R + r) × sin(t) - (r + O) × sin(((R + r) / r) × t)

The outer radius R is entered by the user. The rotating circle radius r and pen offset O are randomly generated each time the drawing starts.

Canvas Controls

Enter a value from 50 to 180. The random value for r will always be less than R.

Random values will appear here after you start the drawing.
